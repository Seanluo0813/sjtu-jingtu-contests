# 竞途 · 2026本科生竞赛导航

面向计算机/信息类本科生，保留算法编程、数据智能、硬件系统、工程开发、网络安全五大类。本项目为课程作品，不是学校官方服务。

当前只收录已核实2026届/2026决赛赛季的54个赛事/赛项，对应47个目录母项。2026年发布的2027届通知不收录；查不到可靠2026信息的候选不展示。目录材料年份与赛事事实年份分开，详见[目录依据](ranking-source.md)和[84项筛选记录](catalog-audit.md)。未确认独立2025或2026分析报告原件，2023—2025公开目录仅作候选校对。

报名窗口：10项完整、12项单端、32项精确日期未核实。未知保留空值；跨年赛季保留2025年真实报名时间。52项支持团队；32门课程为编辑关联建议，不能代替官方资格。

## 功能与运行

方向、年级、形式和课程筛选；关键词搜索；收藏；最多3项对比；报名日历；数据观察和CSV导出。前端拒绝非2026或未经当届核实的数据。按钮悬停柔和变色，无白色闪光；手机版隐藏滚动框，保持可滑动。

仓库根目录为完整静态网站，GitHub Pages从main发布；无需构建。直接打开index.html可离线演示，也可运行 `python3 -m http.server 8000`。数据由本地data.js载入，收藏只存当前浏览器。外部通知需要网络。
